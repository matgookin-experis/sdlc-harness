What stays Markdown, and why

A few files in this repository are read by tools, not just people, so converting them to HTML would change what they do, not just how they look:

  • bob-kit/skills/sdlc-harness/SKILL.md, the skill definition Bob's skill loader reads directly.
  • AGENTS.md and bob-kit/rules/01-sdlc-harness.md, read by AI coding agents and Bob by filename convention.
  • README.md at the repository root and inside gitlab-local/, bob-kit/, and bob-kit/mcp-server/, since GitHub/GitLab auto-render README.md as the folder landing page (an HTML file doesn't get that treatment), and the same applies to weather-app/WEATHER-DASHBOARD.md and weather-app/tests.md, which are pushed as literal content into the seeded demo GitLab project by seed.sh and rendered there.
